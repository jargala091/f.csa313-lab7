# BUG-10: Он талбарт тоон бус string утга өгсөн ч ном үүсгэж байна

**Орчин:** Уншлагын жагсаалт v2.0, Google Chrome / macOS, 2026-10-20

**Урьдчилсан нөхцөл:** `node app.js` сервер ажиллаж байгаа. API хүсэлт илгээх боломжтой.

## Дахин гаргах алхам

1. Terminal нээнэ.
2. Төслийн `lab7` хавтас руу орно.
3. Дараах API хүсэлтийг илгээнэ:

   ```bash
   curl -i -X POST http://localhost:3000/api/books \
     -H 'Content-Type: application/json' \
     -d '{"title":"Test Book","author":"Test Author","year":"abc"}' \
     2>&1 | tee evidence/bug-10-curl.txt
   ```

4. HTTP статус болон хариуны биеийг шалгана.
5. `evidence/bug-10-curl.txt` файлыг нээнэ.

**Хүлээгдэж байсан:** Он нь 1000–2100 хоорондох бүхэл тоо байх ёстой. `"abc"` нь тоон утга биш тул ном үүсгэх хүсэлтийг татгалзаж, алдааны хариу буцаах ёстой.

**Бодит үр дүн:** `HTTP/1.1 201 Created` статус болон `{"result":"OK","id":9}` хариу буцсан.

**Ноцтой байдал:** Major — буруу өгөгдөл номын жагсаалтад орж, өгөгдлийн чанар алдагдах боломжтой.

**Хавсралт:** `evidence/bug-10-curl.txt`

**Олдсон аялал:** Saboteur (API түвшний довтолгоо)

# BUG-09: Байхгүй номын ID-г устгахад амжилттай гэсэн HTTP 200 статус буцааж байна

**Орчин:** Уншлагын жагсаалт v2.0, Google Chrome / macOS, 2026-10-20

**Урьдчилсан нөхцөл:** `node app.js` сервер ажиллаж байгаа. `http://localhost:3000` хаягаар апп нээгдэж байна.

## Дахин гаргах алхам

1. Terminal нээнэ.
2. Төслийн `lab7` хавтас руу орно.
3. Дараах хүсэлтийг ажиллуулна:

   ```bash
   curl -i -X DELETE http://localhost:3000/api/books/99999 \
     2>&1 | tee evidence/bug-09-curl.txt
   ```

4. Terminal дээрх HTTP статус болон хариуны биеийг шалгана.
5. `evidence/bug-09-curl.txt` файлын гаралтыг шалгана.

**Хүлээгдэж байсан:** Байхгүй ID-тай номыг устгах үед хүсэлт амжилттай биелсэн мэт хариу өгөхгүй, тухайн ном олдоогүйг илэрхийлсэн алдааны хариу өгөх нь зохистой.

**Бодит үр дүн:** `HTTP/1.1 200 OK` статус болон `{"result":"OK"}` хариу буцсан.

**Ноцтой байдал:** Minor — байхгүй өгөгдөлд амжилттай устгасан мэт хариу өгч, хэрэглэгч болон API хэрэглэгчийг төөрөгдүүлж болзошгүй.

**Хавсралт:** `evidence/bug-09-curl.txt`

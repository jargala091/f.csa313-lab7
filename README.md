## Тестийн үр дүн

“Уншлагын жагсаалт” веб аппликейшнийг Exploratory Testing аргаар шалгаж, ном нэмэх, хайх, устгах, номын тоолуур, UI болон API-ийн ажиллагааг туршив.

Тестийн явцад нийт **10 согогийн ажиглалт** бүртгэсэн. Үүнд оролтын утгын баталгаажуулалт, хайлтын ажиллагаа, номын тоолуур, товчны өнгө болон API-ийн HTTP хариутай холбоотой асуудлууд багтсан. API-ийн шалгалтын `curl -i` гаралтуудыг `evidence/` хавтсанд хадгалсан.

## Дүгнэлт

Энэхүү exploratory тестийн session-д Supermodel аяллаар ном нэмэх, хайх болон интерфэйсийн ажиллагаатай холбоотой согогуудыг илрүүлсэн бол Saboteur аяллаар API болон өгөгдлийн баталгаажуулалтын алдаануудыг олсон. BUG-01 болон BUG-05 нь ном нэмэх үеийн оролтын шалгалттай, BUG-02 болон BUG-04 нь хайлт болон номын тоолууртай холбоотой асуудлууд байв. Харин BUG-06–BUG-10 согогуудыг API-д буруу, дутуу болон хүлээгдээгүй өгөгдөл илгээж шалгах явцад илрүүлсэн. Туршилтын явцад серверийг дахин эхлүүлж анхны өгөгдлийг сэргээхгүй бол өмнөх тестийн өгөгдөл дараагийн шалгалтын үр дүнд нөлөөлж болохыг ажиглав. Дараагийн session-д он жилийн зөвшөөрөгдөх хязгаар, хил утгууд болон API-ийн буруу оролтын баталгаажуулалтыг илүү нарийвчлан шалгахаар үлдээв. Илэрсэн согогуудаас номын тоолуурын зөрүү болон API-ийн хариуны статус кодтой холбоотой асуудлуудыг зөв assertion бичсэн тохиолдолд Playwright автомат тестээр илрүүлэх боломжтой. Мөн устгах товчны өнгө болон номын жилийн формат зэрэг харагдах байдлын согогийг автоматжуулсан UI шалгалтаар илрүүлж болох боловч үүний тулд өнгө, форматтай холбоотой тодорхой шалгуур бичсэн байх шаардлагатай. Иймээс автомат тест нь урьдчилан тодорхойлсон шаардлагыг тогтмол шалгаж, регрессээс сэргийлэхэд тустай бол exploratory тест нь урьдчилан төлөвлөөгүй нөхцөл болон санаанд ороогүй согогийг илрүүлэхэд үр дүнтэй болохыг ойлголоо.
